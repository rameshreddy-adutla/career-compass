# Career Compass roadmap

Proposed work for a personal engineering-development tool. Verify scope against any work already completed outside this repository before starting an evaluation session. Estimates describe future work, not hours already worked.

## 1. Editable development cycles and goals (8 to 10 hours)

Create and revise a cycle in the UI, define goals and observable outcomes, and connect actions to them. Preserve existing records and distinguish changing a plan from rewriting its history. Let users describe their own career expectations.

Check: create a cycle and goal, add actions, revise the plan, reload and inspect the previous plan.

## 2. Weekly planning and review (6 to 8 hours)

Create weekly plans and reflections through the UI. Compare planned activities with completed actions and record what to try next. Keep learning activity separate from demonstrated work outcomes.

Check: plan a week, record a reflection, change the next week and confirm the earlier record stays intact after reload.

## 3. Complete backup and restore (6 to 8 hours)

Add a versioned backup format for all records and configuration. Validate imports, preview changes and resolve conflicting records before writing. Keep the current workspace intact when an import is invalid or storage fails.

Check: round-trip a populated fictional workspace in a clean browser; reject malformed and unsupported backups without changing existing data.

## 4. Verification and accessibility (6 to 8 hours)

Keep deterministic storage and migration checks, browser journeys and keyboard checks in the repository. Cover populated workspaces, mobile layouts, invalid saved data and failures. Document setup and known limitations.

Total proposed effort: 26 to 34 hours, dependent on confirmed scope. The current rebrand and fictional-data cleanup are preparation and are not included in this estimate.
